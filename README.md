## How to update this index

The catalogue above **updates itself**. Every push to `main` (including files uploaded through GitHub's "Add file → Upload files" button) runs the [Update README catalogue](.github/workflows/update-readme-index.yml) workflow, which rebuilds the section between the `CATALOGUE` markers and commits the new README.

- **Add a file:** upload or push it anywhere in the repo. It appears automatically, titled from the PDF's own metadata or its filename, under its folder's section.
- **Give it a proper title, author, date, section or description:** add an entry under `"files"` in [`catalogue.json`](catalogue.json), keyed by its path, for example:
  ```json
  "library/classics/1897-heath-the-works-of-archimedes.pdf": {
    "title": "The Works of Archimedes", "author": "T. L. Heath", "date": "1897",
    "category": "classics", "description": "Optional one-line note", "licence": "Public domain"
  }
  ```
- **Add a new section:** add it to `"categories"` (order there is the order shown here), and optionally map a folder to it in `"folder_categories"`.
- **Rebuild by hand** (optional): `python3 scripts/build_index.py` (Python 3, no installs). `--check` reports whether the README is current.
- Only the text between the markers is regenerated; edit anything else in this README freely.

Folder layout: own papers sit at the repository root (kept there so existing links keep working); `library/` holds public-domain reference texts by subject; `data/` holds datasets; `OmniArchitect_SSR_CRA_Omega-1.0-Sovereign/` is the GitHub Pages site.
